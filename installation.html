Getting Started: Installing Hermes

Ready to experience the power of autonomous agentic workflows? Installing Hermes is designed to be seamless, whether you are a developer or an end-user.

1. Prerequisites

Before installing, ensure you have a modern terminal environment and a Python 3.10+ installation. We recommend using a virtual environment to keep your system clean.

2. Installation via CLI

The easiest way to get up and running is using the official installation script:

curl -sSL https://get.hermes-agent.nousresearch.com | bash

Alternatively, you can install the package via pip:

pip install hermes-agent

3. Initial Configuration

Once installed, you need to set up your environment. The Hermes setup wizard handles model selection, provider configuration, and terminal settings:

hermes setup

Follow the interactive prompts to connect your preferred LLM provider (e.g., OpenAI, Anthropic, or local models via Ollama).

4. Verifying Installation

To ensure everything is working correctly, run the doctor command:

hermes doctor

If all checks pass, you are ready to start your first session!

5. Launching Your First Session

Simply type the following to enter the interactive chat mode:

hermes
